# Lógica de Programação com Python

Repositório criado para armazenar exercícios desenvolvidos durante meus estudos iniciais de **lógica de programação utilizando Python**.

Os códigos presentes neste projeto trabalham problemas simples de programação com o objetivo de desenvolver raciocínio lógico e familiaridade com os principais recursos da linguagem.

## Conteúdos Praticados

Entre os exercícios presentes no repositório estão:

- Criação e utilização de funções
- Uso de `def`
- Utilização da função `main`
- Estruturas condicionais
- Estruturas de repetição
- Entrada e saída de dados
- Operações matemáticas
- Comparação de valores
- Cálculo de médias
- Geração de sequências numéricas
- Sorteio de números
- Manipulação de variáveis

## Objetivo

O objetivo deste repositório é registrar meus primeiros exercícios com Python e acompanhar a evolução do meu aprendizado em lógica de programação.

Esses exercícios serviram como base para conteúdos mais avançados estudados posteriormente, como estruturas de dados, orientação a objetos e desenvolvimento de aplicações.
